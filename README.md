# D.S Engineering Automobile

## **Project Description:**

**D.S Engineering Automobile** is a modern and fully responsive web application built with **Next.js, Tailwind CSS, ShadCN UI, and Framer Motion**. This project showcases the services, gallery, and expertise of **D.S Engineering Automobile**, ensuring a seamless user experience with smooth animations and a clean UI.

### **Key Features:**

✅ **Fully Responsive:** Optimized for all devices, including desktops, tablets, and mobiles.  
✅ **Animated UI:** Smooth scroll-based animations powered by Framer Motion.  
✅ **Service Showcase:** A dedicated section for automobile engineering services.  
✅ **Gallery Section:** Display images and videos of previous works.  
✅ **Contact Form with Email Integration:** Users can reach out via a working email form.

### **Tech Stack:**

- **Next.js** – Fast and SEO-friendly framework
- **Tailwind CSS** – Utility-first styling for modern design
- **ShadCN UI** – Prebuilt UI components for consistency
- **Framer Motion** – Smooth animations and interactions
